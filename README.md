# Домашнее задание: Параллельное считывание файлов

ДЗ по курсу C# — занятие 10 «Введение в параллелизм в .NET».

## Задание

1. Прочитать 3 файла параллельно и вычислить количество пробелов в них (через `Task`).
2. Написать функцию, принимающую путь к папке. Из этой папки параллельно прочитать все файлы и вычислить количество пробелов в них.
3. Замерить время выполнения кода (`Stopwatch`).

## Структура проекта

| Файл | Назначение |
|---|---|
| `Program.cs` | Точка входа. Запускает задачи и замеряет время через `Stopwatch`. |
| `FileSpaceCounter.cs` | Логика подсчёта пробелов. Основные методы: `Task1_ConcurrentTask`, `Task2_ManyFilesTask`. Экспериментальные — в `#region Experimental Part`. |
| `FileGenerator.cs` | Генерирует тестовые данные: `File1/2/3.txt` для задачи 1 и 100 файлов `test_file_*.txt` для задачи 2. |
